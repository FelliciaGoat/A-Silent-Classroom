Colab notebook

The backend runs from this notebook. Open it, run the server cell, and paste the printed public URL into the Backend box above.

Open in Google Colab
https://colab.research.google.com/drive/1ECh1OZQ_7dmj78yfV2suaMqe7sLJmj6G?usp=sharing

Start the backend

  1. Upload main_pipeline.py to the Colab file panel.
  2. Paste colab_backend.py into one cell and set NGROK_TOKEN to your ngrok authtoken.
  3. Run the cell and keep it running. It prints a URL like https://xxxx.ngrok-free.app.
  4. Paste that URL into the Backend box and press Connect. The dot turns green.

How to read the output

Doubt: raised arm, pointing finger or confused face Attentive Looking away

The confusion score is a simple rule on DeepFace emotions (surprise + fear + sad above 45%). It is a hint for the teacher, not a validated measure.
